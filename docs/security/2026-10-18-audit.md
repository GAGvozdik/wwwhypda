## Стенд и границы

Три уровня локальной проверки: анонимные HTTP-запросы; просмотр кода и целевые
пробы форм; HTTP-действия двух обычных пользователей и администратора.
Werkzeug HTTP server и отдельный Gunicorn запускаются внутри контейнеров без
внешней сети. Аккаунты/SQLite синтетические; PostgreSQL — отдельный Compose project
`wwwhypda-security-010-audit`, internal network, tmpfs, без опубликованных портов.
После тестов его контейнеры и сеть удалены. SMTP/Google/IMAP заменены protocol mocks.
Проверяется настоящий application verifier, но не антибот-решения Google.

Это целевой аудит, а не полная сертификация ASVS. Рабочие dev-контейнеры, env,
почтовые ящики, VPS, DNS и пользовательские данные не изменялись. Production TLS,
фактические cookie/CORS/proxy настройки, сеть OVH, инфраструктурный DDoS, browser
DOM XSS и полный перечень WSTG не выдаются за проверенные. Новая мобильная вёрстка
ещё не реализована; предоставленные скриншоты просмотрены.

## Зависимости: требуется отдельный security-update шаг

Проверены lock/requirements и актуальные advisory OSV/разработчиков. Первичный
batch OSV дал неполный результат для PyPI; его пустой ответ не означает отсутствие
уязвимостей. Шесть Python-пакетов перепроверены отдельными запросами. Полный
повторяемый inventory/проверка build tools обязательны в новом плане.

- npm: axios 1.14.0, react-router 7.14.0, xlsx 0.18.5 и ряд транзитивных пакетов
  имеют advisory. Node-only adapter/SSR/RSC/build-only случаи нельзя объявлять
  удалённым RCE Flask/SPA. Для Router проверить клиентские redirects/route matching.
- xlsx используется json_to_sheet/writeFile, чтение чужих Excel файлов не найдено:
  известная атака через импорт файла здесь не воспроизведена.
- Werkzeug 3.1.3: special-device safe_join advisory относится к Windows;
  Linux-container не выдаётся за Windows-exploit.
- Flask 3.1.0: fallback keys и некоторые Vary/Cookie сценарии требуют соответствующих
  настроек/кэша; эти условия в production не подтверждены.
- Jinja2 3.1.5: sandbox breakout требует контроля над шаблоном, такого пути не найдено.
- Requests 2.32.4 extract_zipped_paths напрямую приложением не вызывается;
  urllib3 2.5.0 streaming/proxy условия не воспроизведены; Flask-CORS 5.0.0 требует
  исправлений и проверки фактического allowlist, который не читался из env.

Наличие affected dependency подтверждено; эксплуатация всех её CVE на этом сайте — нет.
Не выполнять npm audit fix --force или бездумную установку latest.
