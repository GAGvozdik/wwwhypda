# Цель

Добавить в существующую радиогруппу Search вариант `All parameters`. Выбор конкретной породы и этого варианта возвращает все её образцы со всеми доступными измерениями/параметрами. Выбор корня `All rock types` (нынешняя подпись `-- generic earth material --`) и конкретного параметра возвращает измерения этого параметра по всем породам. Всё выполняется одной явной кнопкой поиска в существующей таблице. Корень дерева и группы выделяются размером/жирностью; каждый вложенный уровень получает дополнительный отступ. Дополнительно: вертикальная полоса прокрутки всей страницы постоянно видна на всех страницах сайта, без изменения ширины интерфейса при переходах. Панели дерева/формы/результатов независимо скрываются и раскрываются с анимацией, оставшиеся занимают свободное место. На страницах аккаунтов Logout находится сверху слева, Delete account — внизу слева.

## Объём и ограничения

- Реализация только локально; архитектор изменяет только документацию. Не выполнять VPS/DNS, реальные письма, commit/push, миграции и изменения production-данных. Серверная диагностика в чате не разрешает развёртывание этого цикла.
- Цикл 005 архивирован. Сохранить его фиксированную высоту Search 44rem, zoom/reflow, непрерывную навигацию, раннюю тему и удаляемый CAPTCHA iframe.
- Разрешено необходимое расширение Flask rocks API и запроса моделей, frontend Search, типов/словаря, тестов и описаний контракта. По уточнениям владельца также разрешены минимальные общие стили постоянной вертикальной полосы прокрутки страницы, управление видимостью и анимация Search-панелей, перенос действий Logout/Delete account в обычном и административном аккаунте. Изменения схемы БД для этих фильтров не нужны.
- Только публичный научный каталог Sample/Measure/Rock_type/Parameter. Не подключать InputData, users_db, профили, контакты, частные заявки или поля их авторов к публичному поиску.
- AG Grid только Community. Сохранить экспорт XLSX, сортировку, фильтры, пагинацию, темы, шрифт Afacad_Flux, Redux и черновики. Не удалять комментарии/закомментированный код.
- Не включать в цикл новую систему таблиц, server-side pagination, pivot, изменение поисковой семантики остальных родительских узлов дерева или переработку auth/CAPTCHA. Их визуальное оформление и отступы входят в этот цикл.

## Текущее поведение и подтверждения

- `src/components/search/search.tsx`: `selectedValue` — number/null; один execute `search`, затем GET `/rocks/samples/{rt_id}/{selectedValue}` с `X-Recaptcha-Token`. Изменение радиокнопки и дерева само по себе не запускает поиск.
- `wwwhypda-backend/rocks/rocks_bp.py`: старый endpoint принимает только int/int; `Sample.getSamplesByRockType` фильтрует по точному key_rt, затем Measure — по одному id_par_msr. Специального режима Generic material и all parameters нет.
- Результат сейчас — плоский массив измерений; таблица генерирует колонки по ключам первой строки. Нельзя терять повторные измерения одного образца/параметра, складывая их в одно скалярное значение.
- ID и положение Generic material в рабочем каталоге не установлены из исходников. Не придумывать ID 0/-1/1 и не считать любой родительский узел запросом всех пород.
- Серверный инцидент 16.10.2026: по выводу владельца backend и db были Exited (0), Nginx сообщал `backend could not be resolved`. После `start db` и `start backend auth-code-cleanup` GET `/api/rocks/parameters` вернул HTTP 200. Это восстановление данного API; не доказательство проверки всех маршрутов/worker. Не планировать исправление схемы БД на основании прежнего 502.

## Планируемое поведение

| Выбор в дереве | Параметр | Результат |
| --- | --- | --- |
| Конкретная порода | Конкретный параметр | Все существующие измерения этого параметра для образцов именно этой породы; прежняя семантика |
| Конкретная порода | All parameters | Все образцы именно этой породы и все их измерения по всем параметрам |
| All rock types | Конкретный параметр | Все образцы каталога, имеющие измерения этого параметра, независимо от породы |
| All rock types | All parameters | Все образцы публичного каталога и все их измерения |

- Для прочих папок сохраняется прежняя точная фильтрация по выбранному rt_id, без автоматического включения потомков.
- Представление сохраняет существующую плоскую таблицу: одна строка на измерение, с идентификатором/именем образца, породой, параметром и единицами. У образца с несколькими измерениями будет несколько строк. Не усреднять, не брать первое/последнее и не удалять совпадающие значения.
- В режиме All parameters образец без измерений тоже представлен одной строкой с nullable полями измерения; отсутствующее значение не заменять нулём. При конкретном параметре такой образец не подходит.
- All parameters — отдельный режим, не запись справочника Parameter и не фиктивный числовой ID.

### Название корня дерева

Новая видимая подпись на странице Search — `All rock types`, без декоративных дефисов. Все оставшиеся упоминания Generic material в контракте/тестах ниже означают эту же исходную запись каталога, а не вторую опцию. Исходное имя из API и стабильный rt_id сохраняются; отображение и идентичность разделены.
