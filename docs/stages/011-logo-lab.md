# Цель

Локально реализовать отдельную отключаемую страницу /logo-lab: существующий логотип как исходный образец и 18 новых векторных композиций из реальных названий пород каталога Search. Для каждой новой композиции — четыре цветовые схемы, четыре конечные анимации, независимый повторный запуск, независимая подложка и увеличенный просмотр.

## Объём и ограничения

Этот файл — план будущей реализации. В текущем поручении архитектору действует завершающее «Код не меняй»: разрешены исследование и документация. Вложенное требование «приступай к реализации» относится к цели следующего цикла и не отменяет этот запрет. Реализацию выполняет имплементатор по отдельному поручению.

- Только локальная работа. VPS, публикация, DNS, production-конфигурация, реальные письма, commit/push исключены.
- Не менять текущую Home, её логотип, порядок анимации и навигацию ради экспериментов. Не добавлять ссылку в основное меню.
- Стек сохраняется: React/TypeScript/Vite, SCSS Modules, MUI, существующий GSAP. Новые тяжёлые библиотеки не нужны.
- Не менять backend, БД, Redux, auth/CSRF/CAPTCHA, существующий API transport, поиск/дерево и сохранённые пользовательские данные. Не добавлять новый store или систему тем.
- Бренд везде WWHYPDA. Перестановка WWHYDPA запрещена.
- Референсы использовать только для композиционных принципов, не вставлять их как готовые логотипы.
- UI остаётся английским по правилам проекта, кроме явно заданной пользователем кнопки «Запустить анимацию»: это точное локальное исключение. Короткие строки, включая эту кнопку, хранить в общем словаре.
- Отключение клиентского маршрута — выключатель эксперимента, не защита приватной информации. Страница содержит только публичный каталог; настоящие ограничения доступа не изобретать.

## Исследованное текущее поведение

Все пути ниже отсчитываются от корня репозитория.

- Активного плана до этого цикла не было. Последний архив — 010-security-and-mobile.md; рабочее дерево при начале исследования чистое.
- Маршруты: wwwhypda-frontendV2/src/App.tsx содержит BrowserRouter и стабильную оболочку; src/components/mainWindow/mainBody.tsx — Routes внутри ModalProvider. /logo-lab отсутствует. Отдельного общего механизма experimental flags в src/common не найдено.
- src/components/search/search.tsx использует src/components/tree/mainTree.tsx. Последний получает RockTypeData[] через api.get('/rocks/rock_type'), дерево строит treeBuilder.tsx. У группы есть дочерние записи; корень определяет common/catalog.ts по generic earth material, а не числовому sentinel.
- Backend rocks/rocks_bp.py и rocks/rocks_models.py подтверждают публичный GET /rocks/rock_type без body/query. Возвращаются rt_id, rt_name, rt_description, rt_wiki_link, rt_left, rt_right, rt_id_parent, rt_USCS, UID, PARENTUID, rt_status. Нужные поля уже описаны в common/types.ts, интерфейс RockTypeData.
- Просмотрен только участок публичной таблицы Rock_type из db_dumps/wwhypda_dump.sql. Есть многословные названия и пунктуация: Sandstone, chanel; Marls, flood plain; Loam, with clay sandy. Не исправлять исходную орфографию. Встречаются пробелы по краям. Дамп — историческое подтверждение структуры, не источник runtime и не разрешение скопировать список. Текущий каталог должен быть проверен при реализации.
- Палитра и размеры — src/components/menu.module.scss. Светлая палитра в :root, тёмная в :global(:root[data-theme="dark"]), .dark. Применяются Redux isDarkTheme, localStorage.isDarkTheme, common/theme.ts и public/theme-bootstrap.js. Токены: --body-color, --form-color, --tree-text, --logo-color, --buttons, --menu-hover и другие. Их наличие не доказывает достаточный контраст для мелких слов.
- Подключён Afacad_Flux, variable TTF в src/assets/fonts/Afacad_Flux. В доступных файлах шрифтов найден Afacad Flux; исходного подключаемого шрифта геометрии логобукв не найдено. SVG букв не являются текстовым шрифтом.
- src/logos/logo содержит A.svg…Z.svg и as.svg…zs.svg. Имена F.svg/fs.svg подтверждены содержимым: заглавная/строчная f, заполненные path без stroke. W.svg: viewBox 0 0 108 86, реальный path примерно 107.378 × 85.511. P.svg и A.svg имеют внутренние просветы в compound path.
- WWHYPDA.svg: viewBox 0 0 580 105; внутри mask stroke0_1_2 есть составной заполненный path всех семи букв с просветами. Не использовать внешнюю контурную полосу как заполненный силуэт. Предпочтительно извлечь именно заполненный path из этого локального проверенного SVG: он сохраняет исходные интервалы/выравнивание. W.svg — источник одиночной W.
- Home импортирует src/logos/logo/AnimatedLogo.tsx без props. Компонент использует useId, memoized letters, локальные refs и GSAP timeline; cleanup уничтожает timeline/listener. Для букв расширяются прямоугольные reveal masks (0.75 s, power2.inOut, перекрытие 0.42 s); master timeScale 2.2. Это проявление контурной формы маской, не stroke-dashoffset-прорисовка. Reduced motion завершает timeline. Логотип также анимирует геометрический знак.
- Просмотрены все три референса: файл ALPHABET-CAPS-White.webp фактически показывает Z из слов; jpg с сердцем — преимущественно горизонтальные слова разных размеров; второй jpg — LIFE с плотной укладкой 0°/90°. Важны целые слова, иерархия размеров, ровные интервалы и читаемый силуэт; содержание и стандартные шрифты референсов не переносить.

## Контракт желаемого решения

### Данные и состояние

Один запрос каталога на страницу через существующий src/components/api.tsx, без новых endpoints, POST и CAPTCHA. Состояния loading/error/empty/retry обязательны. Не рендерить вымышленные слова при ошибке. AbortController/защита от позднего результата при уходе.

В новом src/components/logoLab/rockNames.ts сделать чистый extractor из RockTypeData[]:
исключить идентифицированный корень, все parent=-1 и все узлы с детьми; использовать непустые leaf rt_name целиком после удаления только внешних пробелов. Не разделять по пробелам/запятым и не исправлять написание. Дедупликация одинаковых отображаемых имён, стабильная сортировка по имени/ID. Проверить фактические листья на служебные записи; при неоднозначности исследовать метаданные каталога и зафиксировать фильтр, не придумывать denylist пород и не считать rt_status доказанным классификатором категорий.

Общие State/RockTypeData переиспользовать. Специфичные новые типы держать в logoLab/types.ts: CompositionId, Group A/B/C, PaletteMode, RevealMode, PreviewSurface, WordPlacement (исходный ID/имя, x/y, fontSize/weight, rotation 0|90, bbox, стабильный order/colorSlot). Карточка хранит свои palette/reveal/surface/replayVersion, увеличенный просмотр использует те же настройки и готовые координаты. В Redux/localStorage ничего не добавлять.

### Геометрия и вычисления

- Масштабируемый SVG с настоящими текстовыми элементами; раскладка является источником силуэта, её нельзя заменять залитой буквой под облаком слов.
- geometry.ts получает заполненные paths из локальных SVG, учитывает viewBox, transforms, fill-rule/nonzero и просветы P/D/A. Никаких похожих системных W или растягивания отдельных названий.
- Нормализовать W и wordmark в достаточно крупное координатное поле; для C использовать область «диск минус центральная W». У W прозрачный фон, без закрашивающей заплаты. Опциональные masks — страховка/эффекты, не способ скрыть непомещающиеся слова.
- Детерминированный packing.ts: фиксированные seeds/config для каждой композиции; шрифт сначала загрузить через document.fonts.load/ready. Использовать стабильные weight/метрики Afacad Flux, измерять реальные glyph bounds (actualBoundingBox/проверка SVG getBBox после рендера), учитывать пробелы, поворот и зазор.
- Принимать слово только целиком: консервативный bbox с отступом должен полностью входить в разрешённую область. Проверка лишь центра/четырёх углов недостаточна для вогнутых букв и просветов. Допустима вспомогательная raster occupancy + integral image на этапе packing с консервативной границей; итоговый рендер остаётся SVG. Каждая проверяемая ячейка bbox должна быть допустима, диск/W-hole/просветы исключены.
- Пересечения bbox с padding исключать пространственным индексом. Размещать от крупных к мелким; для остаточных мест искать подходящие целые названия из всего списка. Не уменьшать ниже порога ради заполнения. Не разрешать textLength с неравномерным искажением.
- Баланс повторов: обход слов с учётом количества использований, без повторного выбора нескольких коротких имён для большинства мест. Диагностика сообщает распределение/уникальные имена; при достаточном каталоге ни одно имя не занимает >5% размещений. Не отбрасывать длинные имена заранее: дать им крупные продольные зоны.
- В увеличенном режиме при масштабе 100% минимальная видимая высота шрифта 12 CSS px; карточка — обзор, для чтения предусмотрено увеличение. В SVG внутренние размеры задаются общей шкалой --logo-lab-word-* в палитре; zoom/viewBox не искажают aspect ratio.
- Кэшировать готовый результат по fingerprint каталога + версии геометрии/шрифта/packing + ID композиции. Цвет, тема, replay, открытие dialog и resize не входят в ключ и не запускают packing заново.
- Генерировать по видимости карточек, очередью с yield/отменой либо Worker, не блокируя управление. Ограничить число попыток и объём слов; записать время/число SVG nodes. Нельзя упрощать 18 вариантов до смены seed при одинаковой структуре.

### Цвет и движение

Четыре режима каждой новой карточки: mono; два контрастных цвета; два семейства оттенков с несколькими уровнями светлоты/насыщенности; согласованная многоцветная палитра. Стабильный colorSlot назначать при packing, сами цвета — через CSS tokens.

Новые tokens --logo-lab-surface-light/dark, --logo-lab-ink-light/dark-1…N и шкалу word sizes определить только в menu.module.scss. Использовать оттенки существующей бирюзовой/песочной/нейтральной палитры с коррекцией контраста. Явные light/dark наборы должны быть доступны на любой теме страницы; локальный surface scope выбирает alias tokens без изменения html, Redux или storage. Для каждого реально используемого маленького текста проверить contrast >=4.5:1 на выбранной подложке; несколько уровней не должны содержать нечитаемые бледные слова. Проверить и mono, и все цветовые слоты.

Режимы reveal (точные английские названия в словаре, соответствующие поведению):
1. Soft reveal — все слова одновременно плавно появляются (opacity, power2.inOut), без обещания прорисовки контура.
2. Left to right — целые слова появляются с задержкой по x; плавность/easing как у масок исходного образца, без отрезания частей слова бегущим clip.
3. Word sequence — небольшие stagger задержки в фиксированном порядке, ограниченная общая длительность.
4. Centre outward — задержка по расстоянию от центра с мягким opacity; без пересекающихся движущихся слов.

Анимации конечные, по завершении всё видно. По загрузке новые карточки показывают итог без autoplay. Все эффекты меняют только визуальное проявление, координаты не меняются. Переключение настроек само не запускает анимацию. Replay останавливает/сбрасывает и запускает только выбранный экземпляр; работает повторно в процессе проигрывания. Cleanup GSAP/timers/listeners, useId для SVG refs/masks и dialog, reduced-motion сразу показывает итог (также при смене media query во время проигрывания).

Исходный образец использует неизменённый AnimatedLogo.tsx. На lab монтировать его только после нажатия replay, при повторе менять key; до первого запуска показать статическое конечное состояние исходной векторной геометрии без создания активного timeline. Это небольшой lab-only wrapper OriginalLogoPreview.tsx: не копировать монолит AnimatedLogo целиком. Если для точного статичного образца нужна общая геометрия, разрешено только выделение констант без изменения Home поведения с отдельной регрессией; предпочтительнее переиспользовать локальные refs/assets без правки текущего компонента. Статичный образец должен включать и знак, и название. Независимая подложка применяется и к образцу.
