## Объём и ограничения

Этот файл — план будущей реализации. В текущем поручении архитектору действует завершающее «Код не меняй»: разрешены исследование и документация. Вложенное требование «приступай к реализации» относится к цели следующего цикла и не отменяет этот запрет. Реализацию выполняет имплементатор по отдельному поручению.

- Только локальная работа. VPS, публикация, DNS, production-конфигурация, реальные письма, commit/push исключены.
- Не менять текущую Home, её логотип, порядок анимации и навигацию ради экспериментов. По указанию владельца добавить Logo lab в основное меню, используя MenuButton и общий LOGO_LAB_ENABLED.
- Стек сохраняется: React/TypeScript/Vite, SCSS Modules, MUI, существующий GSAP. Новые тяжёлые библиотеки не нужны.
- Не менять backend, БД, Redux, auth/CSRF/CAPTCHA, существующий API transport, поиск/дерево и сохранённые пользовательские данные. Не добавлять новый store или систему тем.
- Бренд везде WWHYPDA. Перестановка WWHYDPA запрещена.
- Референсы использовать только для композиционных принципов, не вставлять их как готовые логотипы.
- UI полностью английский, включая Play animation. Короткие строки хранить в общем словаре; кнопки и поля переиспользуют стили сайта submitButton/inputField.
- Отключение клиентского маршрута — выключатель эксперимента, не защита приватной информации. Страница содержит только публичный каталог; настоящие ограничения доступа не изобретать.

### Геометрия и вычисления

- Масштабируемый SVG с готовыми контурами слов Afacad Flux 600 и полными именами в title; раскладка является источником силуэта, её нельзя заменять залитой буквой под облаком слов.
- geometry.ts получает заполненные paths из локальных SVG, учитывает viewBox, transforms, fill-rule/nonzero и просветы P/D/A. Никаких похожих системных W или растягивания отдельных названий.
- Нормализовать W и wordmark в достаточно крупное координатное поле; для C использовать область «диск минус центральная W». У W прозрачный фон, без закрашивающей заплаты. Опциональные masks — страховка/эффекты, не способ скрыть непомещающиеся слова.
- Детерминированный packing.ts: фиксированные seeds/config для каждой композиции; метрики из wordOutlines.snapshot.json соответствуют рисуемым SVG-контурам. После рендера проверить getBBox обёрток use. Учитывать пробелы, поворот и зазор; не выполнять runtime font loading/canvas text measurement.
- Принимать слово только целиком: консервативный bbox с отступом должен полностью входить в разрешённую область. Проверка лишь центра/четырёх углов недостаточна для вогнутых букв и просветов. Допустима вспомогательная raster occupancy + integral image на этапе packing с консервативной границей; итоговый рендер остаётся SVG. Каждая проверяемая ячейка bbox должна быть допустима, диск/W-hole/просветы исключены.
- Пересечения bbox с padding исключать пространственным индексом. Размещать от крупных к мелким; для остаточных мест искать подходящие целые названия из всего списка. Не уменьшать ниже порога ради заполнения. Не разрешать textLength с неравномерным искажением.
- Баланс повторов: обход слов с учётом количества использований, без повторного выбора нескольких коротких имён для большинства мест. Диагностика сообщает распределение/уникальные имена; для исходных 12 конфигураций при достаточном каталоге ни одно имя не занимает >5% размещений. В шести крупных вариантах допустимо до12 повторов одного имени: длинные названия физически не помещаются в узкие штрихи при очень крупном размере; сохранять полное имя, не уменьшать его скрытно. Не отбрасывать длинные имена заранее: дать им крупные продольные зоны.
- Размеры слов задаются конфигурацией в координатах SVG и масштабируются по unitsPerEm готовых контуров; viewBox сохраняет aspect ratio. Палитра задаётся CSS tokens.
- Кэшировать готовый результат по fingerprint каталога + версии геометрии/шрифта/packing + ID композиции. Цвет, тема, replay и resize не входят в ключ и не запускают packing заново.
- Генерировать по видимости карточек, очередью с yield/отменой либо Worker, не блокируя управление. Ограничить число попыток и объём слов; записать время/число SVG nodes. Нельзя упрощать 9 вариантов до смены seed при одинаковой структуре.

### Цвет и движение

Только Multicolour: согласованная многоцветная палитра без переключателя. Стабильный colorSlot назначать при packing, сами цвета — через CSS tokens.

Новые tokens --logo-lab-ink-light/dark-1…N и шкалу word sizes определить только в menu.module.scss. Использовать оттенки существующей бирюзовой/песочной/нейтральной палитры с коррекцией контраста. Inks используются из тёмного набора сайта; фон карточек и preview — существующий --body-color, без отдельной подложки. Для каждого реально используемого маленького текста проверить contrast >=4.5:1 на выбранной подложке; несколько уровней не должны содержать нечитаемые бледные слова. Проверить все используемые цветовые слоты.

Режимы reveal (точные английские названия в словаре, соответствующие поведению):
1. Left to right — целые слова появляются с задержкой по x; плавность/easing как у масок исходного образца, без отрезания частей слова бегущим clip.
2. Word sequence — небольшие stagger задержки в фиксированном порядке, ограниченная общая длительность.
3. Centre outward — задержка по расстоянию от центра с мягким opacity; без пересекающихся движущихся слов.

Анимации конечные, по завершении всё видно. По загрузке новые карточки показывают итог без autoplay. Все эффекты меняют только визуальное проявление, координаты не меняются. Переключение настроек само не запускает анимацию. Replay останавливает/сбрасывает и запускает только выбранный экземпляр; работает повторно в процессе проигрывания. Cleanup GSAP/timers/listeners, useId для SVG refs/masks, reduced-motion сразу показывает итог (также при смене media query во время проигрывания).
