# Активный план

Здесь может находиться только один план NNN-short-name.md. Единственный указатель — docs/STATE.md. README не является планом.

Архитектор создаёт план по ../templates/stage.md. После завершения имплементатор переносит его в ../archive с тем же именем. Шаблоны, история и будущие темы здесь не хранятся.
